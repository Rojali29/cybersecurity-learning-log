## Commands I practiced

### Navigation
- `pwd` — shows the current folder.
- `ls` — lists files and folders in the current folder.
- `cd folder-name` — moves into a folder.
- `cd ..` — moves back one folder.
- `cd ~` — goes to the home folder.

### Files and folders
- `whoami` — shows the current username.
- `mkdir folder-name` — creates a folder.
- `rmdir folder-name` — removes an empty folder.
- `touch file-name` — creates an empty file.
- `nano file-name` — opens a simple text editor.
- `cat file-name` — shows the contents of a file.
- `rm file-name` — permanently deletes a file.

### Permissions
- `ls -l file-name` — shows detailed information about a file, including permissions.
- `r` means read.
- `w` means write.
- `x` means execute.
- Permissions are shown for the owner, group, and others.

## Important lessons
- Linux is case-sensitive: `Desktop` and `desktop` are different.
- Spaces in folder or file names need quotation marks.
- `rm` permanently deletes files, so I must be careful.
- `mkdir` creates folders, while `touch` creates files.
- `cd` moves me between folders, while `mv` moves or renames files
