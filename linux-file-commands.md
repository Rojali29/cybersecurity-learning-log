# Linux File Commands

## What I practiced

- `touch linux-notes.txt` creates an empty file.
- `nano linux-notes.txt` opens a simple text editor.
- `cat linux-notes.txt` shows the contents of a file.
- `cp linux-notes.txt backup.txt` copies a file.
- `mv backup.txt old-notes.txt` renames a file.
- `rm old-notes.txt` permanently deletes a file.

## Important lesson

- `rm` permanently deletes a file.
- I should be careful before using `rm`.
- I should not use `rm -r` until I understand folders and recursive deletion.
